# LogistiFlow

Plataforma de gestión logística orientada a operaciones reales, inventario, estanterías y control de almacén con foco en rapidez, trazabilidad y decisiones operativas.

## Qué incluye

- Dashboard operacional en tiempo real
- Inventario por SKU con filtro por estado
- Mapa visual de estanterías y ocupación por zona
- Cola de picking con tiempos estimados
- Alertas de bajo stock y riesgo operativo
- Vista enfocada en eficiencia logística y trazabilidad

## Objetivo

LogistiFlow ofrece una experiencia más ágil, visual y accionable que soluciones tradicionales de ERP como SAP, sin depender de complejidad excesiva ni procesos burocráticos.

## Cómo ejecutarlo

1. Descarga o clona este repositorio.
2. Abre `index.html` directamente en el navegador.
3. Si prefieres servirla vía local, ejecuta:

```bash
python -m http.server 8000
```

Luego abre: http://localhost:8000

## Estructura

- `index.html`: interfaz principal
- `styles.css`: diseño visual del sistema
- `app.js`: lógica de datos y rendering

## Propuesta de valor

La mejora real frente a SAP en este contexto es la simplicidad operativa: más claridad visual, menos fricción, menos pasos y un modelo de control mucho más cercano al almacén real.
